## 1. 评级映射

### 目标

把三家机构的符号体系映射到一个**有序数值刻度 1-21**，使迁移距离、回归系数与
概率预测有定义。

### 模型

映射 $m: \mathcal{S} \to \{1, \dots, 21\}$ 满足：

1. **单调性**：若符号 $s_1$ 优于 $s_2$，则 $m(s_1) > m(s_2)$
2. **机构一致性**：同一信用档位在三家机构下映射到相同数值
3. **满射**：每个分值都有至少一个符号对应

具体映射表见 `docs/data_dictionary.md` 第 1 节。

### 实现细节

* **符号清洗**：先尝试直接查表；失败后去除括号注释（`(P)`、`(pi)`、`(sf)`）、
  上标字符（`*`、`†`）、尾部单字母修饰符（`u`、`p`），再查表。
  清洗顺序保证了 `AA+u` → `AA+`、`C/Du` → `C/D` 这类边界情形正确。
* **机构识别**：`normalize_agency` 支持 20 余种别名（`SP`、`Standard & Poor's`、
  `MOODYS`、`Fitch Ratings` 等）。机构未知时退化为**跨机构搜索**。
* **缺失语义区分**：`no_rating`（`NR`/`WR`/`WD`）、`short_term`（`A-1+`/`P-1`/`F1`）、
  `unmapped`（无法识别）与 `missing`（空值）在 `rating_map_reason` 中分别记录，
  便于区分「数据缺失」与「解析失败」。
* **不抛异常**：无法映射返回 `NaN`，由调用方决定丢弃或保留。

### 假设与局限

| 假设 | 何时失效 |
| --- | --- |
| 符号顺序即信用质量顺序 | 机构修订评级定义（如 2010 年后 S&P 对结构化产品的调整，主权评级影响小） |
| 档位间距等距 | **确实不等距**——AA 与 AA- 之间的违约概率差远小于 B 与 CCC 之间。若研究对间距敏感，应改用违约概率映射（需外部数据） |
| 违约类评级可合并 | 若研究关注「选择性违约 vs 完全违约」的区别，需使用原始符号列 |
| 长期评级与短期评级可分离 | 若数据中混有短期评级而未标注，会误判为缺失 |

## 2. 面板构建

### 目标

把**事件式**评级记录（只在变化时记录）转换为**国家-年份-机构**面板。

### 模型

对每个 $(i, a)$ 组合（$i$ = 国家，$a$ = 机构）：

$$
\text{score\_in\_effect}_{i,a,t} = \text{score}_{i,a,\tau}, \quad
\tau = \max\{s \le t : \text{存在行动}\}
$$

$$
\Delta\text{Rating}_{i,a,t} = \text{score\_in\_effect}_{i,a,t} - \text{score\_in\_effect}_{i,a,t-1}
$$

### 实现细节

1. **年内多次行动的聚合**：按 `action_date` 排序，取**年末状态**（`tail(1)`）。
   若研究关注年内动态，应保留原始记录（面板中同时保留了 `action_date`）。
2. **平衡网格**：用「实体 × 年份」的笛卡尔积生成完整网格，缺失年份标记为
   `has_action = False` 而不是丢弃该行——保留空行是构造迁移矩阵的前提。
3. **前向填充**：`score_in_effect` 在实体内部前向填充，**不设上限**
   （评级在下次行动前一直有效）。
4. **宏观左连接**：以评级面板为主表，避免因宏观缺失而丢失评级观测。

### 假设与局限

| 假设 | 何时失效 |
| --- | --- |
| 年末状态代表全年 | 若评级在年内多次变动且研究关注年内波动 |
| 评级在未更新的年份持续有效 | 机构可能「撤回评级」（withdrawn），此时不应继续沿用。可通过 `WR`/`WD` 标记识别并中断填充 |
| 所有机构对同一国家在同一时间存在 | 实际存在机构进入/退出（如 Fitch 在某些年份未覆盖某国），面板会自动产生缺口年份 |

## 3. 缺失值处理

### 三类缺失，三种策略

| 类型 | 判据 | 策略 | 实现 |
| --- | --- | --- | --- |
| **未知** | 指标存在，某年未采集 | 组内线性插值，`limit=2` | `interpolate_within_group` |
| **结构性缺失** | 指标在某年尚未开始统计 | 保留 `NaN` | `limit_direction="forward"`（默认不填序列开头） |
| **粘性变量的缺失** | 评级等具有持续性的变量 | 组内前向填充 | `impute_panel(method="ffill")` |

### 关键设计：为什么 `limit_direction="forward"`

假设某指标 2000-2005 年缺失，2006 年起有数据。若用 `"both"`，
2000-2005 会被回填为 2006 年的值——这等于**凭空造出 5 年数据**，
且会在时间序列上制造一个虚假的「水平突变」。

默认 `"forward"` 意味着只填补「第一个有效观测之后」的内部缺口。这是保守的、
可辩护的选择。

### 插值上限

`limit=2` 表示最多填补 2 个连续缺口。理由：长缺口插值实际上是外推，
线性插值会给出一个平滑但虚假的趋势。若某指标长期缺失，正确的做法是
在模型中用 `*_was_missing` 标记处理，而不是插值。

### 可追溯性

* 每个被填补的单元格都会在 `<column>_imputed` 列中标记
* `handle_missing` 返回 `(处理后的数据, 对比报告)`，报告含填补前后缺失数与填补数
* 回归模型可用 `*_imputed` 作为稳健性检验的变量

### 局限

* 线性插值假设变量在缺口期间线性变化，这对剧烈波动变量（汇率、通胀）不成立
* 未实现多重插补（multiple imputation）——若缺失比例高（>20%），
  单一插值会产生偏误，应考虑 MICE 等方法
* 未处理**非随机缺失**（MNAR）——例如低评级国家更容易缺失数据，此时
  插值会系统性高估其评级

## 4. 迁移矩阵

### 模型

定义一步迁移概率：

$$
P_{jk} = \Pr(\text{Rating}_{t+1} = k \mid \text{Rating}_t = j)
$$

估计量为频数比：

$$
\hat{P}_{jk} = \frac{N_{jk}}{\sum_{k'} N_{jk'}}, \qquad
N_{jk} = \#\{(i,a,t) : \text{Rating}_{t}=j,\ \text{Rating}_{t+1}=k\}
$$

### 实现细节

* **只统计相邻年份**：要求 `to_year == year + 1`。这是本实现最重要的细节——
  若不限制，跨度 2 年的观测会被当作「一年期迁移」，低估评级粘性。
* **完整刻度**：矩阵固定为 21×21，未出现的档位保持为 0。
  行和为 0 的行在归一化时保持 0（而非 `NaN`），便于直接绘制热力图。
* **有效样本量提示**：少量观测的行会出现 0% 或 100% 的极端概率。
  文档与 notebook 建议只解读行样本量 ≥ 20 的行。

### 统计推断的缺失（重要局限）

本实现给出的是**点估计**，没有置信区间。在样本量小的档位上，
「BBB+ 的迁移概率是 12%」可能完全不显著。论文中若要做跨期或跨机构比较，
需要：

* Bootstrap（按国家整块重抽样，保留面板内的相关性）
* 或对矩阵元素做多项分布检验

这两项列在后续工作中。

## 5. 上调下调概率

### 定义

$$
p_{\text{up}} = \Pr(\Delta > 0), \quad
p_{\text{down}} = \Pr(\Delta < 0), \quad
p_{\text{stable}} = \Pr(\Delta = 0)
$$

三者之和为 1。

### 两个容易混淆的口径

| 口径 | 分母 | 用途 |
| --- | --- | --- |
| **无条件概率** | 全部迁移观测 | 「明年被下调的概率是多少」 |
| **条件概率**（`p_*_given_change`） | 发生变动的观测 | 「如果评级要变，是变好还是变坏」 |

两者数值差异巨大。媒体报道「评级下调概率 30%」时通常指前者。
本实现在同一张表中同时输出两列，避免误用。

### 多期下调概率

`downgrade_probability(horizon=h)` 计算：

$$
\Pr(\text{Rating}_{t+h} < \text{Rating}_t)
$$

要求 `future_year == year + h`，同样不允许跨缺口。

### 局限

* 未对**评级迁移的序列相关**做调整——同一国家连续下调会重复计入，
  使得概率估计的方差被低估
* 未做**利率/宏观状态条件化**——「BB 档在有汇率危机时下调概率是多少」
  需要交互项或分组回归

## 6. 评级周期

### 定义

一个**片段（spell）**是「实体处于同一评级档」的最长连续年份区间。

$$
\text{duration} = \text{end\_year} - \text{start\_year} + 1
$$

### 关键陷阱：右删失

片段在样本期末仍持续时，其观测到的时长是真实时长的**下界**。
直接对全部片段取平均会**系统性低估**平均时长。本实现：

* 提供 `ongoing` 列标记右删失片段
* 在 `rating_cycle_stats` 中额外报告 `share_ongoing`

正确的做法是生存分析（Kaplan-Meier 或 Cox 模型），列为后续工作。

### 另一陷阱：按年份计数 vs 按观测计数

若数据本身有缺口，`end_year - start_year + 1` 会高估时长。
本实现按**年份跨度**计算（假设评级在缺口期间持续有效），
这在面板构建阶段已由前向填充保证一致性。

## 7. 面板回归

### 模型

$$
y_{it} = \alpha_i + \gamma_t + \beta' X_{it} + \varepsilon_{it}
$$

* $\alpha_i$：国家固定效应（吸收地理、制度传统、文化等不随时间变化的因素）
* $\gamma_t$：时间固定效应（吸收全球共同冲击）

### 估计

* **首选**：`linearmodels.panel.PanelOLS`（within 变换，统计推断更规范）
* **退化**：若环境缺少 `linearmodels`，使用「虚拟变量 + 聚类稳健 OLS」。
  两种方法的**系数完全一致**，方差估计在小样本下略有差别。
  返回结果的 `method` 字段会明确标注使用了哪一种。

### 标准误

$$
\hat{V}_{\text{cluster}} = \left(\sum_g X_g' X_g\right)^{-1}
\left(\sum_g X_g' \hat{u}_g \hat{u}_g' X_g\right)
\left(\sum_g X_g' X_g\right)^{-1}
$$

默认按**国家**聚类（`entity_col`）。理由：同一国家跨年的扰动项高度相关
（政策延续性、制度惯性）。忽略聚类会使标准误低估数倍，把无关变量误判为显著。

**聚类维度选择的权衡**：

| 聚类维度 | 适用条件 |
| --- | --- |
| 国家 | 国家是社会经济的独立决策单元（默认，最常用） |
| 国家×机构 | 若关注机构行为差异且认为机构评估相互独立 |
| 年份 | 若关注横截面相关（年份数太少时不可用） |

### 因变量

| 因变量 | 模型 | 系数解释 |
| --- | --- | --- |
| `rating_change` | 线性 | 解释变量变动 1 单位，评级变动多少档 |
| `is_downgrade` | 线性概率模型（LPM） | 下调概率的边际变化 |
| `is_upgrade` | 线性概率模型（LPM） | 上调概率的边际变化 |

LPM 的系数可直接解释为概率的边际效应，代价是预测值可能超出 $[0,1]$。
本实现同时提供 `fit_logit` 作为稳健性检验。

### 假设与局限

| 假设 | 说明 |
| --- | --- |
| **严格外生性** | $E[\varepsilon_{it} \mid X_{i1}, \dots, X_{iT}, \alpha_i] = 0$。**这个假设在评级研究中很难成立**：评级机构使用前瞻性信息，宏观变量与评级变动互为因果 |
| **无动态面板偏误** | 若加入滞后因变量，固定效应估计会产生 Nickell 偏误，需用 Arellano-Bond 等 GMM |
| **平行趋势** | 双向固定效应只吸收可加的共同冲击，不处理国家特定的时变混淆因素 |
| **线性形式** | 真实关系可能非线性（债务/GDP 超过阈值后效应陡增），需分位数回归或阈值模型 |

**结论**：本项目的回归结果应解释为**条件相关**，不能作为因果效应。
若研究需要因果结论，需要额外设计（如评级标准变动的外生性、断点回归）。

## 8. 有序概率模型

### 模型

$$
P(y_i \le j \mid x_i) = F(\theta_j - x_i'\beta)
$$

* $F$ = logistic（Logit）或 $\Phi$（Probit）
* $\theta_1 < \theta_2 < \dots < \theta_{J-1}$：待估阈值

于是

$$
P(y_i = j \mid x_i) = F(\theta_j - x_i'\beta) - F(\theta_{j-1} - x_i'\beta)
$$

### 关键实现细节：常数项不可识别

阈值 $\theta_j$ 会吸收线性指数中的常数项：

$$
F(\theta_j - (x'\beta + c)) = F((\theta_j - c) - x'\beta)
$$

因此设计矩阵中加入常数会导致**不可识别**（Hessian 奇异、拟合不收敛）。
本实现在 `_as_design` 中自动剔除 `const` / `intercept` 列并发出警告。

### 并行回归线假设（Proportional Odds）

模型隐含假设：解释变量对「跨越任意相邻档位」的效应相同。

**检验方法**：Brant 检验，或分别拟合二元 Logit（$y \le 1$ vs $y > 1$、
$y \le 2$ vs $y > 2$，…）并比较系数。

**违反时怎么办**：

* 广义有序模型（generalized ordered logit，允许系数随阈值变化）
* 多分类 Logit（放弃有序性，代价是参数增多）
* 分位数/分档回归

本实现未内置 Brant 检验，列为后续工作。

### 实现

* 类别标签先重编码为从 0 开始的连续整数，避免稀疏档位导致的问题
* 优化方法为 BFGS，`maxiter=500`
* 伪 $R^2$ 使用 McFadden：$1 - \ell / \ell_0$，其中 $\ell_0$ 为等概率模型的
  对数似然
* 提供 scikit-learn 兼容封装 `OrdinalProbabilityModel`，使 sklearn 生态的
  交叉验证工具可直接使用

## 9. 树模型与时间序列交叉验证

### 为什么需要树模型

有序概率模型假设线性指数与并行回归线；树模型不做这些假设，
可以捕捉**非线性与交互效应**（例如「高债务 **且** 汇率贬值」的双重效应）。

### 类别不平衡处理

评级样本极度不平衡。`fit_tree_model(balance_classes=True)` 使用
`compute_sample_weight(class_weight="balanced")`，即样本权重为
$w_i \propto 1 / n_{y_i}$。不加权时模型会退化为「永远预测众数」。

### XGBoost 的类别编码

XGBoost 要求类别标签为从 0 开始的连续整数。评分为 1-21 且样本中可能缺少
某些档位（例如没有处于 CCC- 的国家），因此实现中：

1. 记录原始类别顺序到 `model._sovereign_classes`
2. 内部使用重编码 0..K-1 训练
3. `tree_predict_proba` 负责还原标签

### 时间序列交叉验证

**为什么不能用随机 K 折**：随机切分让模型在训练集中看到测试样本的「未来」。
在面板数据上这尤其严重——模型可以记住某国某年的评级水平，
然后在测试集中「预测」同一国家的相邻年份。

**前向链式（expanding window）**：

```text
fold 1: [2000-2009] → [2010]
fold 2: [2000-2010] → [2011]
fold 3: [2000-2011] → [2012]
fold 4: [2000-2012] → [2013]
fold 5: [2000-2013] → [2014]
```

实现为 `expanding_year_folds`，按**年份**整体切分（同一横截面的所有国家
一起进入测试集），避免横截面内部的信息泄漏。

**滚动窗口（rolling）**：训练窗口固定长度，对结构变化更敏感，
适合研究「参数是否随时间变化」。

### 概率矩阵对齐

各折训练出的模型可能缺少某些类别（折内没有低评级国家）。
`_align_probabilities` 把折内概率矩阵对齐到全局类别集合，
缺失类别填 0 后按行重新归一化，保证样本外概率可比。

### 局限

* 未实现 purged / embargoed 交叉验证（López de Prado 方法）——若特征存在
  跨期泄漏（如移动平均），仍可能有轻微泄漏。本项目的特征均为当期宏观值，
  不涉及跨期窗口，风险较低。
* 样本量小时（本次示例约 400-900 行 × 17 特征 × 21 类别），
  树模型容易过拟合，因此报告的重点是**相邻档位准确率**而非精确命中。

## 10. 模型评估

### 指标全景

| 指标 | 公式 | 为什么要看 |
| --- | --- | --- |
| `accuracy` | $\frac{1}{n}\sum \mathbb{1}[\hat y = y]$ | 基础但易被不平衡误导 |
| `balanced_accuracy` | 各类召回率的算术平均 | 纠正不平衡 |
| `f1_macro` | 各类 F1 的算术平均 | 兼顾精确率与召回率 |
| `mae_ordinal` | $\frac{1}{n}\sum \lvert \hat y - y \rvert$ | 尊重档位距离 |
| `adjacent_acc_k` | $\frac{1}{n}\sum \mathbb{1}[\lvert \hat y - y \rvert \le k]$ | **实务最关心**：方向对不对 |
| `quadratic_kappa` | 二次加权 kappa | 一致性，惩罚远距离错误 |
| `roc_auc_ovr_macro` | OVR 宏平均 AUC | 排序能力 |
| `log_loss` | $-\frac{1}{n}\sum \log \hat p_y$ | 概率校准质量 |

### 下调预警概率

把预测分布按「预测前评级」$r_{t-1}$ 拆分：

$$
\hat p_{\text{down}} = \sum_{k < r_{t-1}} \hat P(y = k), \qquad
\hat p_{\text{up}} = \sum_{k > r_{t-1}} \hat P(y = k), \qquad
\hat p_{\text{stable}} = \hat P(y = r_{t-1})
$$

这是**方向性预警**的度量，比精确档位预测更接近实务需求。

### 核心局限：朴素基线未被自动对比

**「预测明年评级 = 今年评级」** 这一基线在这类高粘性数据上表现极强。
若模型的相邻档位准确率没有显著超过该基线，模型没有增量价值。

本项目的 `cross_validate_model` 输出的指标可以手动与「全部预测上一期值」
的基线比较（用 `oof` 表中 `prior_score` 列作为基线预测即可），
但**未自动计算该对比**——这是重要的后续改进项。

### 统计显著性

交叉验证的折间方差很大（每折只有一年数据）。`summary` 表中的 `std`
是折间标准差，**不是**模型比较的检验统计量。严格比较不同模型需要用
Diebold-Mariano 检验或重复交叉验证。本实现未提供，列为后续工作。

## 11. SHAP 可解释性

### 原理

SHAP 基于 Shapley 值，把预测分解为各特征的加性贡献：

$$
f(x) = \phi_0 + \sum_{j=1}^{p} \phi_j(x)
$$

$\phi_j$ 表示特征 $j$ 对预测的贡献。相对于内置的 `feature_importances_`，
SHAP 的优势是：

1. 有**方向**（正负号）
2. 有**一致性**（不同模型间可比）
3. 支持**局部解释**（单个样本为什么得到这个预测）

### 实现细节

* **解释器选择**：树模型优先用 `TreeExplainer`（精确且快）；
  不支持时退化为 `KernelExplainer`（模型无关但慢）。
* **多分类聚合**：多分类 SHAP 返回「类别 × 样本 × 特征」的数组。
  本实现取各特征的**平均绝对贡献**：

  $$
  \text{importance}_j = \frac{1}{K}\sum_{k=1}^{K} \frac{1}{n}\sum_{i=1}^{n} \lvert \phi_{j}^{(k)}(x_i) \rvert
  $$

  这是全局重要性的常见聚合方式，但**丢失了类别间差异**
  （无法回答「哪个特征最能区分 BB 与 B」）。

* **抽样**：SHAP 计算复杂度随样本量线性增长，默认最多解释 500 个样本
  （`config.yaml` 的 `models.shap.max_samples`）。

* **失败降级**：SHAP 未安装、模型不支持或计算失败时返回 `ok=False` 的
  结果对象并说明原因，不中断流水线。

### 局限

* SHAP 的解释是**模型行为**的解释，不是数据生成过程的解释。
  若模型本身有偏（例如遗漏了重要变量），SHAP 不能揭示这一点。
* 特征间的强相关性会使 SHAP 值在相关特征间任意分配，导致「重要性」不稳定。
* KernelExplainer 的结果依赖背景数据集的选取。

## 12. 事件研究

### 模型

**异常收益**：

$$
AR_{i,t} = R_{i,t} - E[R_{i,t} \mid \mathcal{F}_{t}]
$$

**正常收益**的估计：

$$
R_{i,t} = \alpha_i + \beta_i R_{m,t} + \varepsilon_{i,t}
\quad \text{（市场模型）}
$$

$$
E[R_{i,t}] = \overline{R}_{i,\text{est}}
\quad \text{（均值调整模型）}
$$

**累积异常收益**：

$$
CAR_i = \sum_{t=-20}^{+20} AR_{i,t}, \qquad
CAAR = \frac{1}{N}\sum_{i=1}^{N} CAR_i
$$

### 实现细节

1. **事件日对齐**：以「事件日或之前最近的交易日」为第 0 日。
   若事件日恰逢休市，向前找到最近交易日。
2. **估计窗口**：默认 $[-120, -21]$，与事件窗口不重叠（避免事件本身污染
   正常收益的估计）。
3. **窗口不完整**：若价格序列不足以覆盖完整窗口，截取可得部分；
   若可得部分少于 5 个交易日，丢弃该事件。
4. **模型自动选择**：估计窗口不足 10 个观测，或市场因子无变异时，
   退化为均值调整模型，并在 `model` 字段中记录。
5. **对数收益**：当价格序列全为正时使用对数收益
   （$r_t = \ln(P_t / P_{t-1})$），否则使用简单差分。

### 核心假设与局限

| 假设 | 何时失效 |
| --- | --- |
| **市场模型正确设定** | 利差、汇率的正常行为未必由当地股指驱动；主权债利差更适合用全球风险因子（如 VIX、美国 10 年期）解释 |
| **估计窗口无污染** | 若估计窗口内该国有其他评级事件，$\alpha, \beta$ 被污染 → 应剔除该事件或改用更早窗口 |
| **事件日期无误** | 若数据记录的是「报告发布日」而非「首次公开日」，事件日会滞后，估计的事件前反应会被高估 |
| **孤立事件** | 同一国家短期内多次评级行动造成窗口重叠 → 需剔除或加权 |
| **横截面独立** | 危机期间多国同时被下调，CAR 高度相关 → 简单 t 检验的 p 值严重失真。应使用 BMP 标准化检验或按时间聚类 |

### 统计推断的缺失（重要限制）

本实现输出 AAR / CAAR 的时序路径与逐日 t 统计量：

$$
t = \frac{\overline{AR}_t}{s(AR_t) / \sqrt{N}}
$$

**这个 t 统计量在横截面相关存在时不可用。** 正确的做法（BMP 标准化检验、
按事件时间聚类的标准误）列为后续工作。

### 数据可得性

主权利差（EMBI、CDS）为付费数据，本项目不打包。当高频价格数据不可得时，
`event_study()` 返回 `status="insufficient_data"` 的结果对象并说明限制，
**不使用伪造数据填充**。

可用的公开替代：

* FRED（部分新兴市场国债收益率、汇率、VIX）
* IMF IFS（月度汇率、利率）
* 各国央行 / 财政部公开数据

## 13. 复现与随机性

### 随机性控制

| 环节 | 控制方式 |
| --- | --- |
| 示例数据生成 | 固定种子 `20240625`（`scripts/make_sample_data.py`） |
| 随机森林 / XGBoost | `models.random_state`（默认 42，来自 `config.yaml`） |
| sklearn 交叉验证 | 本项目使用自定义按年切分，不涉及随机划分 |
| SHAP 抽样 | `random_state=42` |
| 缺失值填补 | 确定性算法，无随机性 |

### 运行清单

每次 `python -m src.pipeline` 都会写出 `reports/tables/run_manifest.json`：

```json
{
  "project": "sovereign-rating-lab",
  "version": "0.1.0",
  "generated_at": "2026-09-12T07:00:00+00:00",
  "data_source": "synthetic_sample",
  "warnings": ["..."],
  "steps": {
    "panel": {"n_rows": 1296, "fingerprint": "a1b2c3d4e5f6a7b8", "..." : "..."},
    "migration": {"p_stable": 0.94, "..." : "..."},
    "models": {"ordinal_logit": {"accuracy_mean": 0.42, "..." : "..."}}
  }
}
```

**数据指纹**：`dataframe_fingerprint` 对面板的列名、形状与每列内容做 SHA-256
（取前 16 位）。对**行序敏感**——这是刻意设计，因为流水线中的行序本身
也是结果的一部分。若你用同一份数据跑出不同的指纹，说明中间步骤变了。

**警告列表**：所有「未完成/受限」的事项都会进入 `warnings`，
例如「使用合成数据」「SHAP 未运行」「事件研究缺少高频数据」。
论文附录可直接引用该清单，向读者说明研究的边界。

### 环境复现

* `requirements.txt` 使用**下限约束**（`>=`），便于获取安全更新与新版修复
* 若需要完全固定的环境，请自行 `pip freeze > requirements.lock`
* CI 在 Python 3.11 / 3.12 / 3.13 上分别运行测试，确保跨版本兼容
* `Dockerfile` 提供可复现的容器环境（含中文字体）

### 已知的非确定性来源

1. **BLAS 线程调度**：`numpy`/`sklearn` 在多核下的归约顺序可能影响
   浮点结果的最低位。若需逐位复现，设置 `OMP_NUM_THREADS=1`。
2. **statsmodels 优化收敛**：BFGS 在接近最优点的迭代次数可能受
   浮点环境影响，导致系数最后几位不同。
3. **上游数据源修订**：WDI / WEO 会回溯修订历史值。缓存机制缓解了
   这一问题（本地保存首次下载的快照），但若清空缓存重新下载，数值可能变化。
