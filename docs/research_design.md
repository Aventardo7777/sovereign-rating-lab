# 研究设计

> **项目**：sovereign-rating-lab — 主权信用评级迁移与预测研究
> **版本**：0.1.0
> **文档定位**：说明「研究什么问题、为什么这样研究、边界在哪里」

---

## 1. 研究问题

主权信用评级是国际资本市场定价的核心输入之一。评级变动（尤其是下调）会影响
一国的主权融资成本、银行体系的抵押品价值、以及企业跨境融资条件。本研究项目
围绕以下五个可检验的问题组织：

| 编号 | 研究问题 | 主要产出 |
| --- | --- | --- |
| RQ1 | 主权评级在年度尺度上的**迁移结构**是什么？不同评级档的「粘性」是否不同？ | 迁移矩阵、停留时长分布、迁移熵 |
| RQ2 | **上调与下调的概率是否存在非对称性**？这种不对称随时间、机构、评级档如何变化？ | 条件/无条件迁移概率、多期下调概率 |
| RQ3 | 哪些**宏观基本面因素**与评级变动系统性相关？ | 面板固定效应回归、稳健性检验 |
| RQ4 | 能否用公开宏观数据**预测**评级水平与下调风险？预测能力的天花板在哪里？ | 有序 Logit/Probit、RF、XGBoost、时间序列 CV |
| RQ5 | 评级行动是否伴随**市场异常反应**？反应发生在事件前还是事件后？ | 事件研究、CAR/CAAR |

### RQ1 — 迁移结构

**关注点**：评级并非连续变量，而是离散的、具有次序的类别变量。其动态特征表现为
**长时间不动、偶尔跳跃**。因此不能简单用线性自回归建模，需要迁移矩阵这一工具。

**待检验的假设**：

- H1.1 迁移矩阵的对角线占比显著高于随机迁移的预期（评级具有粘性）
- H1.2 高评级档（AA 及以上）的粘性高于低评级档（B 及以下）
- H1.3 迁移矩阵存在「相邻档迁移为主」的带状结构，跳跃多档的概率迅速衰减

### RQ2 — 上下调不对称

**关注点**：评级机构的评级标准在制度设计上是不对称的——下调往往需要更明确、
更持续的证据，且机构面临「延迟下调」的声誉成本。这导致下调在时间上**聚集**
（危机期间集中爆发）。

**待检验的假设**：

- H2.1 条件于发生变动，下调概率高于上调概率
- H2.2 下调概率的年际波动显著大于上调概率
- H2.3 下调在金融危机年份（2008-2009、2020-2021）显著聚集

### RQ3 — 宏观驱动因素

**关注点**：识别宏观变量与评级变动的条件相关性。**这不是因果推断课题**——
评级机构使用前瞻性信息，宏观变量与评级之间存在反向因果与共同驱动因素。

**核心解释变量分组**（见 `config.yaml` 与 `src/features/macro_features.py`）：

| 组 | 变量 | 理论方向 |
| --- | --- | --- |
| 增长 | GDP 增长率、人均 GDP（对数） | 正 |
| 物价 | CPI 通胀率 | 负（高通胀侵蚀偿债能力） |
| 财政 | 政府债务 / GDP | 负 |
| 外部 | 外债 / GNI、储备 / 进口月数、经常账户 / GDP、出口 / GDP | 外债负，其余正 |
| 金融 | 汇率贬值率、实际利率、主权利差 | 贬值负、利差负 |
| 治理 | WGI 六项指标 | 正 |

### RQ4 — 预测能力

**关注点**：评级具有高粘性，意味着「预测明年评级 = 今年的评级」这一朴素基线
已经很难被超越。因此本项目的预测评估**必须**报告相对于该基线的增益，
否则「准确率 85%」可能毫无信息量。

**关键设计**：用 **t-1 期**宏观特征预测 **t** 期评级，严格避免前视偏差。

### RQ5 — 市场反应

**关注点**：评级行动是否被市场提前预期。若 CAR 在事件日之前就已显著，
说明信息主要通过其他渠道泄漏，评级公告本身的增量信息有限。

## 2. 为什么采用现在的设计

### 2.1 为什么用统一 1-21 刻度

三家机构的符号体系不可直接比较（详见 `docs/data_dictionary.md`）。把评级映射到
有序数值刻度后，才能计算迁移距离、回归系数与预测概率。刻度设计遵循三条原则：

1. **序数保真**：符号顺序即数值顺序，不引入任意间隔
2. **机构对齐**：同一分值在 S&P 与 Moody's 体系下对应同一信用档位
3. **边界明确**：投资级门槛（BBB-/Baa3 = 12）为整数，便于分组比较

### 2.2 为什么按年聚合而非使用全部评级行动

评级行动日期不规则（可能一年数次，也可能数年一次），而宏观数据是年度的。
按年取**年末状态**是标准做法，使得：

- 评级与宏观变量在同一时间粒度上对齐
- 迁移矩阵的元素含义清晰（一年期迁移概率）
- 预测任务的 horizon 明确定义为 1 年

代价是损失了年内多次行动的信息。事件研究（RQ5）保留原始 `action_date`，
以恢复这一信息。

### 2.3 为什么用时间序列交叉验证而非随机 K 折

随机 K 折在这类数据上会产生**严重乐观偏差**：模型可以在训练集中看到某国 2018 年
的评级，然后在测试集中「预测」该国 2015 年的评级——这在真实预测场景中不可能发生。
前向链式切分强制训练集严格早于测试年份。

### 2.4 为什么同时报告多个预测指标

评级分布极度不平衡。以本项目示例数据为例，多数观测集中在 BBB 至 B 区间。
一个「永远预测众数」的模型可以获得不错的准确率。因此必须同时报告：

- **平衡准确率 / 宏平均 F1**：纠正类别不平衡
- **相邻档位准确率**（±1、±2 档）：评级预测的实务价值主要在于方向正确
- **有序 MAE**：尊重档位距离
- **下调方向 AUC**：预警能力（实务中最关心的指标）

### 2.5 为什么不打包评级数据

评级历史是商业授权产品。本项目提供工具与方法，不提供数据。这既是合规要求，
也是方法论立场：**任何实证结论都应当能追溯到研究者自己持有合法权限的数据源**。

## 3. 研究设计的边界与局限

### 3.1 明确的局限

| 局限 | 影响 | 缓解方式 |
| --- | --- | --- |
| **无因果识别** | 面板回归系数只是条件相关，不能解读为政策效应 | 在报告中明确标注；提供事件研究作为补充证据 |
| **样本选择** | 有评级的主权国家本身是「已被国际资本市场接纳」的样本 | 讨论时限制结论的适用人群 |
| **幸存者偏差** | 退市/失去评级的主权退出样本，容易造成向上偏差 | 保留 `withdrawn` 状态标记，不做插值 |
| **评级机构的前瞻性** | 评级已包含宏观数据之外的私有信息，回归的 $R^2$ 天然有限 | 把低 $R^2$ 视为正常而非模型失败 |
| **展望信息未充分利用** | 展望对评级变动有预测力，但本项目的基线模型未纳入 | 列为后续工作；`outlook` 已在面板中保留 |
| **频率错配** | 年度数据无法捕捉年内动态 | 事件研究使用日频数据补足 |
| **重叠事件** | 同一国家短期多次评级行动导致事件窗口重叠 | 事件研究中提供重叠检测与剔除建议 |

### 3.2 数据质量的三类风险

1. **评级映射错误**：带修饰符的符号（`AA+u`、`(P)AAA`）若解析失败会被记为缺失。
   → 缓解：`rating_map_reason` 列记录每条记录的映射结果，可审计。

2. **年份缺口造成伪迁移**：若 t 与 t+2 年有数据而 t+1 年缺失，
   直接比较 t 与 t+2 会制造一次「两年期迁移」。
   → 缓解：迁移矩阵**只统计相邻年份**（`to_year == year + 1`）。

3. **结构性缺失被误填补**：WGI 早期年份缺失是「该指标尚未统计」而非「数值未知」。
   → 缓解：默认插值方向为 `forward`，不填补序列开头的缺失。

### 3.3 复现性约定

* 所有随机过程使用固定种子（`config.yaml` 的 `models.random_state`，默认 42）
* 示例数据使用固定种子 20240625 生成，逐字节可复现
* 每次流水线运行在 `reports/tables/run_manifest.json` 中记录：
  数据来源、面板指纹（SHA-256 前 16 位）、各步骤输出、以及**所有警告**
* 数据源的原始响应缓存在本地，记录 URL 与下载时间

## 4. 项目不做的事

明确划出边界，避免误用：

* ❌ 不提供投资建议、交易信号或信贷决策依据
* ❌ 不做因果推断（没有自然实验、没有工具变量、没有断点回归）
* ❌ 不预测具体的评级行动日期
* ❌ 不打包、不转售、不嵌套任何第三方版权数据
* ❌ 不模拟监管资本计量（这属于巴塞尔框架下的专门课题）

## 5. 后续研究方向

按优先级排序：

1. **生存分析**：用 Cox 比例风险或离散时间风险模型处理评级停留时长的右删失
2. **纳入展望与观察状态**：展望是评级变动的前瞻信号，应作为动态协变量
3. **面板局部投影 / 面板 VAR**：估计评级冲击对宏观变量的动态响应
4. **迁移矩阵的统计推断**：bootstrap 置信区间，检验不同时期/机构矩阵是否相同
5. **机器学习方法的稳健性**：比较不同模型在下调预警上的表现，做严格的前向验证
6. **跨国制度因素**：引入制度质量、资本账户开放度等交互项
7. **主权-银行评级联结**：研究主权评级上限（sovereign ceiling）对银行评级的传导
